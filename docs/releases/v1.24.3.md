# CoreDrive RX v1.24.3

The Android app explains once which battery setting keeps it capturing with the screen off.

## What's new

- **Battery tip in the Android app.** Before the first Connect, a short popup says to set the
  phone's battery setting for CoreDrive RX to **Unrestricted**. Some phones close apps in the
  background to save battery even while the capture notification shows; a OnePlus did so during
  a test walk. The popup shows once; the user guide has the same text.

## Upgrade notes

- **Service-worker cache bumped to `coredrive-rx-v63`.**
- The web app is unchanged apart from the cache bump: the popup only shows in the Android app.
- No data, config or MQTT payload change.
