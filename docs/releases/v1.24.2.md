# CoreDrive RX v1.24.2

The Android app asks for notification permission, so its capture notification shows.

## What's new

- **Android app: notification permission on Connect.** On Android 13 and newer the notification
  "CoreDrive RX is mapping" stayed hidden, because the app never asked to show notifications.
  It now asks right before capture starts. Capture also runs if you refuse; you then only miss
  the notification.

## Upgrade notes

- **Service-worker cache bumped to `coredrive-rx-v62`.**
- New Android dependency: `@capacitor/local-notifications` 8.3.1.
- No data, config or MQTT payload change.
