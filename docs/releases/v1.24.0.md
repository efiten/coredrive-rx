# CoreDrive RX v1.24.0

The first Android app, attached to this release as an APK, plus a few web app changes that came with it.

## What's new

- **Android app** (`coredrive-rx-v1.24.0.apk` below). The same app, built natively with
  Capacitor: Bluetooth and GPS go through Android itself, so it needs no Chrome and keeps
  recording with the screen off. A notification shows while it captures.
- **Choose your deployment in the app.** The APK is not tied to one server. On first start it
  asks for the address of a CoreDrive RX deployment (for example `https://rx.on8ar.eu`); type it,
  or tap **Scan QR code** and scan the code on the CoreScope **Coverage** page. Scanning uses
  the Google code scanner from Play services; phones without them type the address.
- **Screen off.** With the screen off Android stops the app's timers while Bluetooth and GPS keep
  delivering. Each reception and GPS fix now runs the work that was due: uploading, discover,
  region asks, uplink pings and RF samples, and it reopens a dropped CoreScope connection. The
  debug log records when the app is hidden and visible again. Not yet proven on a drive; please
  send a debug log after one.
- **Share debug log** in the app opens the Android share sheet with the log as a `.txt`
  attachment.
- **Home screen name.** The web app is now called **CoreDrive RX Web** when installed, so it can
  be told apart from the Android app. Use one of the two: only one can hold the Bluetooth link to
  the companion. The user guide has a new "Android app" section.
- **Layout** keeps clear of the status and navigation bars on phones that draw edge to edge.

## Upgrade notes

- **Service-worker cache bumped to `coredrive-rx-v60`.**
- **Installing the APK:** allow installs from your browser or file manager when Android asks.
  The APK is signed with the CoreDrive RX release key; later versions install over it and keep
  settings and queue. Test builds from before this release were signed differently: uninstall
  those first.
- **Operators:** the Android app runs at origin `https://localhost`. Add it to
  `corsAllowedOrigins` in CoreScope's config so its CoreScope login, account and node-name lookups work. The
  deployment's `config.json` itself needs no change.
- A web app installed before this version may keep the old name "CoreDrive RX" until Chrome
  refreshes its manifest.
- The MQTT payload did not change.
- Dependency updates: vite 6.4.5, postcss 8.5.32, source-map-js 1.2.2, ip-address 10.7.6.
- Tests: 475 pass (+35).
